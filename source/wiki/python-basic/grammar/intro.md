# 基础语法

本章的内容非常简单，建议你快速阅读，只需要做到理解就可以了，不必可以去记忆，在后续的学习中，你会持续接触他们在并不知不觉掌握他们。

学习注释，你会明白小小的注释却有着极大的用途，对于一份程序来说，几乎可以说是不可或缺的。

学习标识符，为以后学习变量，定义函数，类的名字打下基础。

关于编码，本章不做讲解，因为python3之后，编码问题已经不是什么棘手的问题了，你几乎很难遇到这方面问题，在讲解文件读写时，我会教你如何避免文件读写过程中的编码错误。
