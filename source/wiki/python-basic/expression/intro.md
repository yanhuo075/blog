# 运算符与表达式

程序 = 数据 + 算法

关于数据，你已经学习了8种数据类型，知道他们的类型，了解他们的结构，在学习过程中，你已经接触了一些运算符，在开始学习程序控制语法之前，你还需要学习更多的运算符，掌握这些运算符，才能了解什么是表达式，掌握表达式才能顺利的学习if语句，循环等程序控制语法。

运算符，顾名思义，是对数据进行运算的符号，一共有7种运算符

1. 算术运算符
2. 比较（关系）运算符
3. 赋值运算符
4. 逻辑运算符
5. 位运算符
6. 成员运算符
7. 身份运算符

学完本章内容，你讲掌握如何编写一个表达式，并且能够推理计算表达式的结果。
