# 数据存储导读

只要你的工作与计算机有关，就一定会接触到office软件，常用的诸如word文档，Excel，PPT。他们提供的功能各不相同，但本质上是一致的，他们都存储数据。

如果你希望学会python来做一些事情，那么就一定会涉及到数据的存储，为此，大学里专门设置数据库这门课程。本章主要的内容围绕着数据存储展开，但不是以数据库技术作为专题来讲解，毕竟python入门才是本教程的核心。

本章主要内容包括以下几部分：

1. 文件读写
2. sqlite
3. 序列化

将数据存储到文件中，是最为简单的数据存储方式，它不需要使用任何数据库，而是就地取材，方便快捷。但文件存储只适合存储小规模数据，没有复杂的数据间的关联关系。sqlite是一款非常流行的轻型数据库，它不需要像mysql等关系型数据库那样进行安装和配置，在任何操作系统下都可以直接使用，许多手机端的app就用sqlite作为应用的数据库。序列化在数据传输和数据存储方面应用极为广泛，本教程将向你展示几种序列化的方法。
