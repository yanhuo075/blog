# 排序算法导读

python中的列表提供了sort方法，调用简单，性能最优，还有必要学习排序算法么？这个问题，取决于你学习python的目标和对自身的定位。

第一种情况，你是程序员，那么没什么好讨论的，你要靠它吃饭，如果只会增删改查，注定做一个平庸的程序员。

第二种情况，非职业程序员，但是工作中会用到python来编程，如果你想成为python高手，编程能力更上一层楼，我建议你认真学习本章的内容。坦率的讲，任何一门编程语言都能找出这8种排序算法的示例代码，即便是工作中用到了，你也不必自己从头写。因此学习排序算法的目的不是自己实现排序算法在工作中使用，而是通过练习排序算法来提升思维逻辑能力和组织代码的能力。

第三种情况，纯粹的python爱好者，工作中也用不到，希望自己能写点小程序娱乐一下，那么你可以跳过本章了。
