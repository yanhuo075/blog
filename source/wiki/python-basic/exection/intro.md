# 错误与异常导读

程序员的一生只做两件事情：

1. 写bug
2. 改bug

这当然是一种自嘲的说法，但不可否认的是，编程是一件永远无法避免错误的工作。在写代码时，我们要尽可能的考虑边界问题，性能问题，还要考虑各种可能存在的错误和异常。随着经验的增加，你会慢慢了解这些异常，并掌握处理异常的方法。

本章主要内容包括：

1. 什么是异常
2. 如何捕获异常
3. 主动抛异常
4. 如何分析和收集异常

最后，你将学习19个常见的python的错误和异常，只要能避免这些坑，你的程序就变得安全了。
