# 时间处理导读

在实际应用中，对于时间的处理是极为广泛的需求。在各式各样的数据中，时间以不同的形式存在，有时是时间戳，有时是不同时间格式的字符串。为了对他们进行处理，需要转换成python能够识别和操作的数据类型，本章将讲解3种常见的处理时间的模块，他们分别是

1. time
2. calendar
3. datetime
