# 高阶函数导读

在python基础教程中，你已经接触了一些python函数，例如max， min, sum, len， 这些函数的学习和使用都很简单，在进阶阶段，你需要学习了解更高阶的函数，掌握这些函数，你可以更好的发挥python这门语言的特点，更充分的利用python提供给我们的各项工具。

本章节将介绍以下高阶函数

1. compile
2. locals 和 globals
3. partial-偏函数
4. lambda函数
5. zip
6. map
7. reduce
8. setattr, hasattr, getattr
9. filter
