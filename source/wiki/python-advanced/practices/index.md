# 项目实践导读

python实战项目，python练手项目，这是初学者梦寐以求的资源，本章将和你分享一些小的python练手项目，想要完成这些python实践项目，需要你具备非常扎实的python基础知识，此外，还需要你具备良好的计算机知识。 如果这两样你都不具备，那么学习本小节会非常困难，毕竟，编程不等于编程语言，编程是计算机，工程，编程语言的综合运用。

本章包含的python实战项目代码量通常不会太多，但可以帮助你扩展视野，提供思考，实践，锻炼的机会，已经完成的项目有：

1. 字符画及其原理
2. 找出电脑里遗忘的大文件
3. 制作密码生成器
4. 使用turtle模块画五环
5. 下载文件并添加进度条
6. 发送网站注册后的激活邮件
7. 开发简单的URL短地址生成服务
8. 制作网站登录时的图片验证码
9. 使用socket探测主机开放的端口
10. 获取谷歌浏览器的历史记录，分析一个人的上网行为
11. 用pygame模拟展示冒泡排序过程
12. 取可用wifi信息（windows版）
13. 利用谷歌dns服务器获取本地ip地址
14. 获取电脑cpu的速度
