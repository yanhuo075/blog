# 运维老鸟私藏！这20个脚本太6了

在运维工作中，面对Linux系统是常态。尽管Linux强大，但总能遇到一些让人抓狂的小问题。这篇文章整理了20个特别实用的Linux技巧，它们看似简单，却能让工作效率翻倍，真正帮助你应对日常运维中的各种场景。无论是日常管理、日志分析，还是紧急问题处理，掌握这些命令会让你游刃有余！

#### 一、文件操作小技巧

**1. 快速清空文件内容**

运维中常需要清理大日志文件的内容：

```
cat /dev/null > yourfile.txt
```

执行即将文件清空，却保留文件本身，省去了删除再创建的繁琐操作。

**2. 快速生成一个大文件**

用于模拟磁盘读写测试，可以用以下命令生成 1G 文件：

```
dd if=/dev/zero of=bigfile.txt bs=1M count=1000
```

**3. 批量创建文件**
需要一次生成多个文件？以下命令生成 100 个文件：

```
touch file{1..100}.txt  
```

#### 二、文件查找与清理

**4. 删除扩展名为 `.txt` 的文件**

想删除目录下所有`.txt`文件，可以使用：

```
find . -name "*.txt" -exec rm -rf {} \;
```

**5. 删除 7 天前的文件**

用以下命令快速清理陈旧数据：

```
find . -mtime +7 -name "*.txt" | xargs rm -rf
```

**6. 查找超过 1G 的文件**

找出占用大量存储的大文件并处理：

```
find . -size +1000M
```

将这些巨量文件搬到指定目录：

```
find . -size +1000M -exec mv {} /path/to/destination/ \;
```

#### 三、日志分析与网络监控

**7. 统计日志中访问 IP 数量**

分析访问日志中的独立 IP 数：

```
awk '{print $1}' access.log | sort | uniq | wc -l
```

**8. 找出访问最频繁的 10 个 IP**

定位高频访问源，解决可能的攻击问题：

```
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -10
```

**9. 检查某个页面的访问量**

统计特定资源的访问次数：

```
grep "/my/page.html" access.log | wc -l
```

#### 四、文本处理的神器 `sed`

**10. 文件中替换字符串**

替换文件中的字符串 `old` 为 `new`：

```
sed -i "s/old/new/g" file.txt
```

**11. 在行首添加内容**

为文件的每一行开头加上前缀 "###"：

```
sed -i "s/^/### /g" file.txt
```

**12. 添加新行**

在包含关键行 `we love` 后插入文本：

```
sed -i "/we love/ayou" file.txt
```

#### 五、巧用历史命令

**13. 快速重复上条命令**

上一条命令忘记参数？直接输入：

```
!!
```

它会快速重复刚刚执行的命令！

**14. 执行最近与某字符相关的命令**

需要重复以 `vim` 开头的命令？用：

```
!vim
```

#### 六、网络与接口管理

**15. 查看状态为 UP 的网卡**

仅过滤出正在运行的网络接口：

```
ip addr | awk -F":" '/state UP/ {print $2}'
```

**16. 获取网卡的 IP 地址**

列出所有接口的 IP 信息：

```
ip -o addr | awk '/inet/ {print $2, $4}'
```

#### 七、高效排查工具

**17. 查看特定时间访问用户数**

想知道某小时网站的访问 IP 数量：

```
awk '{print $1, $4}' access.log | grep "11/Dec/2021:09" | sort | uniq | wc -l
```

**18. 通过抓包查看 8080 端口访问情况**

利用 `tcpdump` 抓取访问量最多的 IP：

```
tcpdump -i any dst port 8080 -c 1000 | awk -F "." '{print $1"."$2"."$3"."$4}' | sort | uniq -c | sort -nr | head -10
```

#### 八、其他实用技巧

**19. 查看常用命令排行**

统计最常使用的命令，找到自己的使用习惯：

```
cat ~/.bash_history | awk '{print $1}' | sort | uniq -c | sort -nr | head -10
```

**20. 替换指定目录路径**

将 `haodao.txt` 中的路径 `/etc/dhcp` 替换为 `/home`：

```
sed -i "s:/etc/dhcp:/home:g" haodao.txt
```
