# Windows系统常见蓝屏代码汇总



## Windows系统常见蓝屏代码汇总（一）                                                                              

![图片](https://fastly.jsdelivr.net/gh/yanhuo075/images-repo/upload/20250718092629388.jpeg)

**一、电脑为什么会蓝屏？**

**电脑蓝屏又被叫做蓝屏死机（Blue Screen Of Death）简称BSOD，是因为电脑的Windows系统无法从一个系统错误中恢复过来时，为了保护电脑数据文件不被破坏强制显示的屏幕图像。**

**以后可能就不会有蓝屏了，在Windows11 24H2的更新中，蓝屏死机被黑屏死机所取代了。**

**二、解决蓝屏的核心思路（适合大部分数蓝屏死机）：**

**1）、记录关键信息：**

| **停止代码（Stop Code）**                | **例如：****IRQL_NOT_LESS_OR_EQUAL****SYSTEM_SERVICE_EXCEPTION****KERNEL_SECURITY_CHECK_FAILURE 等** |
| ---------------------------------------- | ------------------------------------------------------------ |
| **导致崩溃的文件名（Caused by driver）** | **例如：****nvlddmkm.sys, dxgkrnl.sys, ntoskrnl.exe 等，非常重要** |
| **蓝屏发生时的操作**                     | **例如：****刚启动？运行特定程序？玩游戏？更新系统或者驱动？** |

**2）、安全重启：**

**一般蓝屏死机之后电脑都会重启，如果卡住了不重启可以长按电源键关机再开机。**

**3）、数据备份：**

**蓝屏死机之后，如果要进行系统还原等比较复杂的操作需要及时备份数据，如果持续蓝屏的话可能有硬件故障的风险。**

**4）、基本检查：**

| **散热**     | **电脑清灰，确保散热良好，检查CPU和GPU的温度（可以用工具查看）。** |
| ------------ | ------------------------------------------------------------ |
| **物理连接** | **检查内存条、显卡、硬盘数据线和电源线是否松动，尝试重新插拔（关机断电操作）。** |
| **外设**     | **拔掉所有非必要的外设，只留鼠标键盘，看看问题是否还在。**   |

**5）、使用诊断工具：**

| **Windows内存诊断**                                          | **搜索“Windows 内存诊断”运行检查内存问题。**                 |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| ![图片](https://fastly.jsdelivr.net/gh/yanhuo075/images-repo/upload/20250718092739246.png) |                                                              |
| **检查修复磁盘错误**                                         | **在命令提示符（管理员）运行：****chkdsk C: /f /r (C盘是系统盘）需要重启** |
| **扫描并修复系统文件**                                       | **在命令提示符（管理员）运行：****sfc /scannow**             |
| **修复系统镜像**                                             | **如果sfc命令无效，可以用DISM修复系统映象**`DISM /Online /Cleanup-Image /RestoreHealth` |
| **查看蓝屏日志**                                             | **文件夹位于C:\Windows\Minidump\（小内存转存）或C:\Windows\MEMORY.DMP（完全内存转存）** |
| **可以使用WinDbg Preview或者BlueScreenView工具分析这些日志文件** |                                                              |



**三、蓝屏代码汇总：**

**1）、高频蓝屏代码：**

**（1）、CRITICAL_PROCESS_DIED(0x000000EF)**

**原因：关键系统进程意外终止。可能是系统文件损坏、驱动问题、磁盘错误、恶意软件或者内存故障。**

**解决：**

| **优先使用DISM /Online /Cleanup-Image /RestoreHealth和sfc /scannow** |
| ------------------------------------------------------------ |
| **运行chkdsk /r**                                            |
| **检查最近安装的软件或者更新，尝试卸载软件或者更新。**       |
| **使用杀毒软件查杀恶意文件**                                 |
| **检查内存（Windows 内存诊断）**                             |
| **尝试系统还原到稳定点（提前做还原点）**                     |
| **最后才考虑重置Windows或者重装系统**                        |

**（2）、 SYSTEM_SERVICE_EXCEPTION (0x0000003B)**

**原因：系统线程或者服务遇到了未处理的异常，非常常见，大多数都是因为有缺陷的驱动引起的（显卡驱动、存储驱动、网络驱动和杀毒驱动的原因比较大），也可能是内存的问题。**

**解决：**

| **重点看导致崩溃的文件名，\**\*.sys的文件是最有可能的驱动**  |
| ------------------------------------------------------------ |
| **更新该设备的驱动程序（去官网下载稳定版本的驱动）**         |
| **如果是刚刚更新了驱动，尝试回滚驱动（设备管理器-选择设备-右键属性-驱动程序-回滚驱动程序）** |
| **暂时卸载可能引起蓝屏的驱动或者软件（尤其是安全软件、虚拟化软件和旧版本硬件工具）** |
| **运行 scf /scannow**                                        |
| **检查内存条（重新插拔、擦拭金手指或者更换内存条）**         |

**（3）、IRQL_NOT_LESS_OR_EQUAL (0x0000000A)**

**原因：驱动程序或者内核模式程序在过高的中断请求级别（IRQL）访问了不该访问的内存地址（经典的驱动问题标志）。特别是网络驱动、声卡驱动和旧驱动。也可能是内存的原因。**

**解决：**

| **重点看导致崩溃的驱动文件名，定位有问题的驱动**     |
| ---------------------------------------------------- |
| **更新或者回滚相关驱动程序（尤其是最近更新的驱动）** |
| **检查是否硬件问题（设备管理器里看看有没有感叹号）** |
| **运行sfc /scannow**                                 |
| **检查内存**                                         |
| **禁用BIOS中的内存缓存或影子选项（老旧系统）**       |

**（4）、DPC_WATCHDOG_VIOLATION (0x00000133)**

**原因： 一个延迟过程调用(DPC)运行时间过长或陷入死循环，导致看门狗超时。通常指向有问题的驱动程序，尤其是存储驱动（SATA/AHCI/NVMe 控制器驱动，如 iaStorAVC.sys, storahci.sys）、显示驱动、网卡驱动。也可能是硬盘故障（尤其是 SSD）。**

**解决：**

| **重点看导致崩溃的文件名**                                   |
| ------------------------------------------------------------ |
| **更新存储控制器的驱动、显卡驱动和网卡驱动（一定要去官网下载驱动）** |
| **检查硬盘健康状态（特别是SSD，用厂商的工具检测）**          |
| **运行chkdsk**                                               |
| **把BIOS中的SATA模式从RAID改为AHCI或者反过来（要小心，可能会导致重装系统）** |
| **禁用快速启动（控制面板-电源选项-电源按钮的功能-更改不可用设置-勾掉快速启动）** |

**（5）、KERNEL_SECURITY_CHECK_FAILURE (0x00000139)**

**原因：内核检测到关键数据结构的损坏或安全问题。常见于驱动兼容问题（尤其是升级之后的系统）、内存损坏、系统文件损坏、**

**解决：**



| **优先使用DISM /Online /Cleanup-Image /RestoreHealth和sfc /scannow** |
| ------------------------------------------------------------ |
| **检查内存（Windows 内存诊断）**                             |
| **更新所有驱动程序，特别是主板芯片组、存储控制器和显卡驱动** |
| **卸载最近安装有可能不兼容的软件**                           |
| **检查磁盘错误（chkdsk）**                                   |

**（6）、PAGE_FAULT_IN_NONPAGED_AREA (0x00000050)**

**原因：系统尝试访问不在内存分页文件中的无效内存地址。很大可能是硬件问题，尤其是内存条。也可能是有缺陷的驱动、系统文件损坏或者磁盘损坏（尤其是分页文件所在盘），也可能是恶意文件。**

**解决：**

| **首先是彻底检查内存问题，可以逐根更换内存条测试（可以创建USB启动盘长时间测试）** |
| ------------------------------------------------------------ |
| **运行sfc /scannow和chkdsk**                                 |
| **检查硬盘健康状况**                                         |
| **更新驱动程序（尤其是存储驱动）**                           |
| **扫描恶意文件**                                             |
| **检查最近安装的硬件**                                       |

**（7）、VIDEO_TDR_FAILURE (0x00000116)**

**原因：显卡驱动程序停止响应并且无法恢复。几乎肯定是显卡驱动或者显卡硬件问题（过热、超频、不稳定或者故障）。**

**解决：**

| **可以使用DDU工具在安全模式下彻底卸载显卡驱动，重新安装官网驱动** |
| ------------------------------------------------------------ |
| **检查显卡温度，清理灰尘并且检查显卡风扇是否正常**           |
| **如果超频了显卡或者CPU，恢复默认频率**                      |
| **降低显卡负载（降低游戏画面和分辨率）**                     |
| **尝试更换显卡的插槽一般是PCIe（台式机）**                   |
| **如果上面都不行，很有可能是显卡硬件故障**                   |

**（8）、NTFS_FILE_SYSTEM (0x00000024)**

**原因：文件系统（NTFS或FAT）驱动程序内部错误（ntfs.sys,fastfat.sys)。通常是由磁盘错误（坏道）、存储控制器驱动问题或者是内存问题，也有可能是硬盘本身的故障引起的。**

**解决：**

| **立即运行chkdsk C: /f /r（C盘是系统盘，需要重启）** |
| ---------------------------------------------------- |
| **检查硬盘健康状况（CrystalDiskInfo）**              |
| **更新存储控制器驱动（主板官网）**                   |
| **检查内存**                                         |
| **硬盘可能损坏（备份数据）**                         |

**（9）、WHEA_UNCORRECTABLE_ERROR (0x00000124)**

**原因：硬件错误架构报告了一个无法由系统恢复的严重硬件错误。非常严重，通常指向底层硬件故障，CPU（过热、超频、故障）、内存（不稳定、故障）、主板（特别是电压调节、总线问题）、PCIe设备（显卡、SSD），也可能和驱动或者BIOS有关。**

**解决：**

| **检查CPU温度，清理灰尘、重新涂抹硅脂，检查散热器是否松动** |
| ----------------------------------------------------------- |
| **如果超频了，立马恢复默认设置，这个原因最常见**            |
| **测试内存（MemTest86+)**                                   |
| **更新主板BIOS驱动到最新稳定版（谨慎操作）**                |
| **更新主板芯片组驱动**                                      |
| **尝试最小化启动系统（只保留CPU，单根内存和集成显卡）**     |
| **硬件可能性极高（CPU、主板、内存），需要更换排查**         |

**（10）、DRIVER_IRQL_NOT_LESS_OR_EQUAL (****0x000000D1）**

**原因：驱动程序在过高的中断请求级别(IRQL)访问了可分页内存。经典的有缺陷驱动程序标志。与 IRQL_NOT_LESS_OR_EQUAL 类似，但更明确指向驱动问题。**

**解决：同（3）、\**IRQL_NOT_LESS_OR_EQUAL (0x0000000A)\****

***\*（11）、UNEXPECTED_KERNEL_MODE_TRAP (0x0000007F)\****

***\*原因：CPU 捕获到一个内核模式陷阱（错误），而内核无法处理。常见原因包括：硬件问题（CPU 过热、超频不稳、故障；内存故障）、不兼容的硬件、BIOS 设置错误（如电压）、损坏的系统文件。\****

***\*解决：\****

| **检查CPU温度，清理灰尘、重新涂抹硅脂，检查散热器是否松动** |
| ----------------------------------------------------------- |
| **关闭所有超频**                                            |
| **测试内存（MemTest86+）**                                  |
| **运行sfc /scannow**                                        |
| **检查 BIOS 设置是否合理（恢复默认设置试试）**              |
| **更新主板BIOS驱动到最新稳定版（谨慎操作）**                |
| **检查是否有不兼容的硬件**                                  |

**（12）、INACCESSIBLE_BOOT_DEVICE (0x0000007B)**

**原因： Windows 在启动过程中无法访问启动卷（通常是系统盘）。启动关键驱动加载失败或磁盘无法识别。常见于：存储控制器驱动问题/变更（如 BIOS 中 SATA 模式从 AHCI 改为了 RAID/IDE 或反之）、磁盘损坏、系统文件损坏、磁盘控制器硬件故障、连接问题、分区表/引导记录损坏。**

**解决：**

| **检查 BIOS 中 SATA 模式设置是否与之前一致（之前是 AHCI，现在不能是 RAID），改了就改回去。** |
| ------------------------------------------------------------ |
| **检查硬盘连接是否松动**                                     |
| **尝试Windows自动修复（通过安装介质启动修复引导）**          |
| **尝试运行命令（管理员）bootrec /fixmbr, bootrec /fixboot, bootrec /scanos, bootrec /rebuildbcd** |
| **运行 chkdsk /r (可能需要从安装介质启动)**                  |
| **如果最近更新了存储驱动或磁盘控制器驱动，尝试在安全模式下卸载或回滚** |
| **检查硬盘是否在其他电脑上可识别**                           |

**（13）、BAD_SYSTEM_CONFIG_INFO (0x00000074)**

**原因： Windows 注册表配置单元文件（特别是 SYSTEM 文件）损坏或无法加载。通常由不正常关机、磁盘错误、内存故障或手动修改注册表错误导致。**

**解决：**

| **尝试Windows自动修复（通过安装介质）**               |
| ----------------------------------------------------- |
| **尝试最后一次正确配置启动**                          |
| **尝试系统还原**                                      |
| **使用命令提示符（管理员）：sfc /scannow和chkdsk /r** |
| **如果之前备份了注册表或系统还原点，可以尝试恢复**    |
| **检查内存**                                          |
| **最后手段可能要重装系统或者还重置Windows**           |

**（14）、CLOCK_WATCHDOG_TIMEOUT (0x00000101)**

**原因：一个处理器核心在规定时间内没有响应中断。强烈指向 CPU 相关问题：CPU 物理故障、严重过热、超频不稳定、电压不足（电源问题或主板 VRM 问题）、BIOS Bug。**

**解决：**

| **立即检查 CPU 温度！ 确保散热器工作正常**        |
| ------------------------------------------------- |
| **立即关闭所有 CPU 超频！ 恢复 BIOS 默认设置**    |
| **更新主板 BIOS/UEFI 到最新版**                   |
| **检查 CPU 是否安装牢固（台式机可尝试重新安装）** |
| **考虑电源问题（电源功率不足或老化）**            |
| **最小化系统测试（排除其他硬件干扰）**            |
| **CPU 或主板硬件故障的可能性很高**                |

**（15）、SYSTEM_THREAD_EXCEPTION_NOT_HANDLED (0x1000007E)**



**这个蓝屏代码和第2个是一样的，请参考第2条：SYSTEM_SERVICE_EXCEPTION (0x0000003B)**

**（16）、KMODE_EXCEPTION_NOT_HANDLED (0x0000001E)**

**原因：内核模式程序产生了处理器无法捕获的异常。通常也是驱动程序问题（文件系统驱动如 ntfs.sys, 存储驱动，硬件抽象层驱动 hal.dll）。也可能是硬件故障（内存、主板）或 BIOS 设置不当。**

**解决：**

| ***\*重点看“导致崩溃的文件名”\****                  |
| --------------------------------------------------- |
| **更新或回滚相关驱动**                              |
| **运行 sfc /scannow 和 chkdsk**                     |
| **检查内存**                                        |
| **检查硬盘健康状况（使用 CrystalDiskInfo 等工具）** |
| **确保 BIOS 设置正确且为最新版本（谨慎更新 BIOS）** |

**四、高级分析工具：**

**1）、WinDbg Preview (Windows Debugger)：**

**微软官方强大的调试工具，分析蓝屏日志文件，可以精确的定位导致蓝屏的驱动或者模块。但是需要一定的学习基础，但是信息准确。**

**2）、BlueScreenView (NirSoft)：**

**免费、轻量和易用。直观显示Minidump的文件中的关键信息，包括停止代码、出发崩溃的驱动和文件、堆栈调用等，非常适合快速定位问题驱动。**

**3）、硬件制造商诊断工具：**

| **内存** | **MemTest86+ (最彻底)**                                      |
| -------- | ------------------------------------------------------------ |
| **硬盘** | **CrystalDiskInfo (查看 SMART 状态), 硬盘厂商工具 (如 SeaTools, WD Diagnostics, Samsung Magician)** |
| **显卡** | **FurMark（压力测试），显卡厂商工具**                        |
| **CPU**  | **Prime95、AIDA64（压力测试和温度监控）**                    |
| **电源** | **难以直接软件测试，通常靠替换法排除**                       |

**注意：遇到蓝屏时，记录停止代码和可能相关的文件名是关键的第一步。然后按照从简单（散热、基本检查、软件驱动）到复杂（硬件诊断、系统修复）的顺序进行排查。最后软件问题可以重装系统，硬件问题可以使用替换法排查。**



## Windows系统常见蓝屏代码汇总（二）

**前面一篇介绍了高频发的蓝屏死机代码，这一篇来介绍一下次高频的蓝屏死机代码。虽然蓝屏代码有上百种，但是常见的蓝屏代码也就是那几十种，重要还是看蓝屏代码的报错信息和报错文件。**

**次高频蓝屏死机代码：**

**1、MEMORY_MANAGEMENT（0x0000001E）**

![图片](https://fastly.jsdelivr.net/gh/yanhuo075/images-repo/upload/20250718092817718.png)

**原因：通常是由于内存管理相关的严重错误引发的，可能是内存硬件故障（常见）、驱动程序冲突、系统文件损坏、硬盘上分页文件问题、恶意的感染或者硬件兼容性问题。**

**解决方案：**

| **拔掉除键盘鼠标之外的所有外设，重启电脑**                   |
| ------------------------------------------------------------ |
| **重新插拔内存条擦拭金手指或者更换内存条或者用MemTest86工具检测内存（****最有可能****）** |
| **检查磁盘健康状态，chkdsk C: /f /r（管理员运行）**          |
| **从官网更新主板驱动**                                       |
| **扫描系统文件DISM /Online /Cleanup-Image /RestoreHealth和sfc /scannow** |

**2、****DRIVER_POWER_STATE_FAILURE (0x0000009F)**

**原因：当系统尝试切换电源状态的时候，某个驱动程序无法正确处理电源请求，导致内核挂起。可能是因为驱动程序冲突、硬件兼容问题、系统文件或注册表损坏或者快速启动冲突。**

**解决方案：**

| **拔掉所有外设仅留鼠标和键盘之后重启**                       |
| ------------------------------------------------------------ |
| **更新官网稳定版驱动（显卡驱动用DDU彻底卸载）**              |
| **禁用休眠和快速启动**                                       |
| **重置电源计划 powercfg /restoredefaultschemes**             |
| **恢复BIOS默认设置，更新BIOS驱动（谨慎使用）**               |
| **清除休眠文件：**`powercfg /h off #关闭休眠del /f /q C:\hiberfil.sys #强制删除残留文件powercfg /h on #重新启用（可选）` |

**针对不同场景：**

| **睡眠唤醒时蓝屏**   | **更新显卡驱动--禁用USB唤醒--关闭网卡允许唤醒计算机**        |
| -------------------- | ------------------------------------------------------------ |

**3、PFN_LIST_CORRUPT (0x0000004E)**
